使用說明

  • 黃色及綠色會用來做判斷，不可隨意更換位置。
  • 載入圖片後，可拖曳格線對準需量測框：
    - 用2條黃色虛線作為使用者想判斷CLK的範圍、用3條綠色虛線依照使用者想判斷的三個偵測電流點。
  • 系統會檢查黃色範圍內的訊號是否呈現「抬升」趨勢 (Rising Edge)，若無則判定為失敗。
  • 批次處理前，所選擇的第一張圖將作為「基準」，用來鎖定後續所有圖片的判定門檻。請確保第一張圖是訊號良好的圖片。
  • 即使有兩千張圖片，系統會自動以五十張批次上傳，會優先依據 ID (檔名中的編號) 進行排序與處理，確保結果順序正確。
  • 若檔名包含 _IR?mA 則優先使用該數值計算。
  • 輸出檔名包含測量數值，失敗圖片不會產生數值。
